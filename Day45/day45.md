# Day 45 – Decision Workflow

## Objective

Created and tested an interactive decision workflow using Claude. The application demonstrates how AI can guide users through a structured decision-making process and provide recommendations based on the provided information.

## Activities Completed

- Read the provided resources.
- Watched the solution video.
- Opened Claude.
- Set the Claude effort level to Low.
- Started a new conversation.
- Pasted the provided decision workflow prompt.
- Answered Claude's interview questions.
- Generated the complete HTML application.
- Saved the generated HTML file.
- Opened the application locally in a browser.
- Tested the complete decision workflow.
- Reviewed the decision process and final output.
- Captured screenshots of the important sections.

## Key Learnings

1. AI can help organize complex decisions into structured steps.
2. Breaking a decision into smaller stages makes the process easier to understand.
3. Providing clear inputs helps produce more relevant recommendations.
4. Interactive workflows can make decision-making more engaging and easier to follow.
5. AI recommendations should be reviewed before making important real-world decisions.
6. A well-designed interface can make complex decision processes more accessible.

## Testing

The generated HTML application was opened locally in a browser and the complete decision workflow was tested from the initial input stage through the final decision.
