# Day 26 – Prior Authorization Workflow Simulator

## Objective
Built and tested an interactive Prior Authorization Workflow Simulator using Claude.

## Features
- Patient scenario creation
- Workflow stage tracking
- Document submission
- Approval, pending, denial, and appeal simulation
- Journey tracker
- Workflow dashboard
- Educational workflow explanation

## Deliverables
- HTML Simulator
- Workflow Screenshots
- Workflow Summary

## Key Learnings
- Learned how prior authorization works in healthcare insurance.
- Understood the required documentation for insurance approval.
- Explored different request outcomes such as approval, pending, denial, and appeal.
- Learned to track workflow stages and processing timelines.
