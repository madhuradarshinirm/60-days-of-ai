# Day 39 – PDF Splitter & Merger

## Objective

Built and tested a browser-based PDF Splitter and Merger application using Claude.

## Activities Completed

- Opened Claude and configured the required effort level.
- Provided the PDF Splitter & Merger requirements.
- Answered Claude's interview question.
- Generated the complete HTML application.
- Saved and opened the application locally in a browser.
- Tested the PDF Splitter functionality.
- Selected pages and generated a split PDF.
- Tested the PDF Merger functionality.
- Combined multiple PDF files into a single PDF.
- Previewed processed PDFs.
- Downloaded the processed PDF files.
- Captured screenshots of the application and results.

## Key Learnings

1. Claude can generate useful browser-based productivity applications from natural-language requirements.
2. PDF splitting allows selected pages to be extracted from a document.
3. PDF merging makes it possible to combine multiple documents into one file.
4. Preview functionality helps users verify the output before downloading.
5. A client-side HTML application can provide useful document-processing functionality without requiring a traditional backend.
