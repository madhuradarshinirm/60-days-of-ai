# Day 40 – AI Assistant Builder

## Objective

Built and tested a custom AI assistant using Claude based on a structured assistant-building prompt.

## Activities Completed

- Opened Claude and set the effort level to Low.
- Started a new conversation.
- Provided the AI Assistant Builder requirements.
- Completed Claude's interview questions using the provided MCQ format.
- Generated the complete AI assistant application.
- Tested the assistant with multiple questions.
- Reviewed the generated system prompt.
- Explored the assistant documentation/configuration panel.
- Captured screenshots of the assistant and its configuration.
- Saved the generated HTML application.
- Added the work to the Day40 GitHub folder.

## Key Learnings

1. A well-defined system prompt helps control an AI assistant's behavior.
2. Structured interview questions can be used to customize an AI assistant before generating it.
3. Claude Artifacts can be used to create interactive applications and tools.
4. Testing an assistant with different types of questions helps identify whether its instructions are working correctly.
5. System prompts are important because they define the assistant's role, behavior, limitations, and response style.
6. AI assistants can be customized for specific tasks instead of relying only on general-purpose conversations.

The generated assistant was tested with multiple user queries to verify that it followed the configured instructions and produced appropriate responses.
