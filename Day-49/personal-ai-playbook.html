What is this?

The Personal AI Playbook is a local, offline tool for reusing your best AI prompts instead of rewriting them from scratch every time. Everything lives in this one file and saves to your browser's local storage — nothing is sent anywhere.

What each section does

  • Dashboard — a quick overview of your workflows and recent activity.
  • Communication / Summarization / Technical Writing / Editing — ready-made prompt templates grouped by the kind of task they help with. Fill in the blanks and copy the result.
  • My Workflows — templates you've written or duplicated yourself.
  • Prompt Builder — assemble a prompt piece by piece (role, objective, context, etc.) instead of using a fixed template. Good when nothing pre-made fits.
  • Loop Builder — takes any prompt and turns it into one that asks the AI to check its own work and improve it automatically, within limits you set.

Welcome to your Personal AI Playbook

This is a set of reusable AI prompt systems, tuned to how you actually work: writing emails and Slack messages, summarizing meetings and docs, and writing technical content like code comments and READMEs — with a focus on cutting down back-and-forth editing.

Nothing leaves your browser. Everything saves to local storage on this device.

Templates, not generic prompts

Every workflow is a fill-in-the-blanks template with variables, an example, and best practices — so you're not starting from a blank page each time.

Use the Prompt Builder when you want to assemble something custom from building blocks like role, tone, and output format.

Make it yours

Favorite the workflows you use most, duplicate and tweak any template, or create your own from scratch. Try the Loop Builder to turn a one-shot prompt into a self-checking, iterating one.
