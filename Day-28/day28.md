# Day 28 – Hospital Admission Readiness Simulator

## Objective
Built an interactive Hospital Admission Readiness Simulator using Claude.

## Features
- Patient admission workflow
- Provider and physician information
- Prior authorization tracking
- Admission readiness score
- Risk analysis
- Governance snapshot
- Final admission decision
- Multiple patient scenarios

## Deliverables
- HTML Simulator
- Workflow Screenshots
- Admission Readiness Report

## Key Learnings
- Learned how hospital admission readiness is assessed.
- Understood the importance of prior authorization in patient admissions.
- Explored documentation, insurance, bed, and clinical risk factors.
- Practiced improving admission readiness through workflow actions.
- Learned how governance and compliance support admission decisions.
